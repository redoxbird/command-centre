Define a label + description for each variable, and per-option labels for choice lists — saved with the command. Types: file, text, number, date, range, select, radio, checkbox, uuid — e.g. {{input.range:18-28}}, {{input.select:mp4,mkv}}, {{input.checkbox:--rm}}, {{input.uuid.autogenerate}}. Add :default to prefill any input — e.g. {{input.color:#f6f6f6}}, {{input.text:hello}}, {{input.select:zip,tar.gz=tar.gz}}, {{input.range:0-100=75}}.
